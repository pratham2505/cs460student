Keyboard & Controls Cheatsheet

All standard CS460 Assignment 2 controls are fully supported along with extra creative studio shortcuts:

W / S
Translate Up / Down (+Z / -Z)
A / D
Translate Left / Right (+X / -X)
Q / E
Translate Forward / Backward (+Y / -Y)
Space
Place / Drop Cube at current cursor
0 - 9
Pick color from 10-shade palette
O
Download scene.json (cubes & camera)
L
Upload / Load scene.json
C
Push current camera view matrix
V
Toggle camera loop tour
F
Toggle Zero-G Flying Cubes mode
X
Trigger Supernova explode / reassemble
M
Toggle Wave Ripple motion
R
Toggle Rainbow Chromatic flow
T
Toggle Camera Auto-Orbit
Mouse: Click & Drag to rotate scene • Scroll to Zoom • Right-click drag to pan.
